# Jinglan Cao — personal academic website

A compact, single-page academic homepage inspired by the centered profile-and-publications layout used by many robotics researchers.

## Local preview

Open `index.html` directly, or run a local server in this folder:

```bash
python3 -m http.server
```

## Before publishing

1. Confirm that `assets/profile.jpg` is the photo you want to make public.
2. Replace the CV file in `assets/CV.pdf` whenever the CV changes.
3. Add Google Scholar or GitHub URLs if you want them shown in the profile links.
4. Update the arXiv publication entry if the paper is accepted or revised.

## GitHub Pages

Create a repository named `<your-github-username>.github.io`, copy the contents of this folder into its root, commit and push, then choose **Settings → Pages → Deploy from a branch → main → / (root)**. The site will be available at `https://<your-github-username>.github.io/`.
